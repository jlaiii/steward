How it works
01

Check

Detects Hermes Agent and Ollama installations, verifies paths and required binaries are present.

paths + binaries
02

Verify

Validates git remotes are reachable, checks GitHub release health endpoints, and confirms directories are writable.

network + permissions
03

Update

Pulls latest code with git pull --ff-only and upgrades dependencies. Skips gracefully if already up to date.

git + pip
04

Health

Runs version checks on each agent to confirm the update didn't break anything.

version checks
05

Report

Generates a timestamped JSON report saved to reports/ with full step-by-step results.

JSON to disk
06

Reboot

Schedules a system reboot in 1 minute. Use --no-reboot to skip, or shutdown -c to cancel.

shutdown -r +1
What you get
⚡

Live by default

Steward defaults to live mode because that's what a steward does. Run it, it works. Use --dry-run if you want to preview.

🔒

5-second abort

Accidentally ran it? Ctrl+C during the countdown to bail out safely. No harm, no foul.

📊

Full reporting

Every run produces a timestamped JSON report with pass/fail/skip status for every step. Audit everything.

🧠

Smart skips

Agents not installed? Dependencies already current? Steward detects it and moves on without failing.

🔄

Fast-forward pulls

Uses --ff-only to avoid merge hell. If your local tree is dirty, it tells you instead of guessing.

🌐

Health validation

Hits GitHub's release API and tests git remotes before touching anything. No blind updates.
